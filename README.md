# CubeMart Recommendation Service

![CubeMart](https://img.shields.io/badge/CubeMart-Recommendation-0f766e)
![Python](https://img.shields.io/badge/Python-Service-3776AB)
![gRPC](https://img.shields.io/badge/gRPC-Recommendations-1f2937)

Recommendation microservice that suggests relevant products based on user browsing context.

## Responsibilities

- Generate product recommendations
- Exclude already viewed products
- Query the product catalog service
- Expose gRPC endpoints for the frontend
